# Visibilidad — checklist para “automatizador”

Objetivo: que en **30 segundos** un visitante entienda *qué problema resuelves* y *cómo contactarte*, sin ver código ni credenciales.

---

## LinkedIn

- [ ] **Portada** con texto corto (ej. *Automatización · Datos · PYME · Telegram/Sheets*).
- [ ] **Titular** alineado con automatización si buscas ese tipo de consultas (opcional según empleo actual).
- [ ] **Acerca de:** 2–4 líneas de portafolio + link a GitHub o página simple (puedes copiar de [`01-bloque-cv-y-portafolio.md`](01-bloque-cv-y-portafolio.md)).
- [ ] **Destacados:** (1) repo o README fuerte, (2) video Loom del **Asistente financiero** o **Selvato**, (3) post corto tipo “antes/después” del problema que resuelves.
- [ ] Publicación fija o destacada que mencione **los dos proyectos fuerte** primero, luego pilotos.

---

## GitHub

- [ ] Repos **públicos** con `README.md` **en español**: problema, capturas, “cómo correrlo” sin secretos.
- [ ] Orden sugerido de impresión: proyecto con mejor **captura visual** (**Selvato**) + proyecto con mayor **profundidad de proceso** (**Asistente financiero**).
- [ ] `.gitignore` para `.env`; nunca subir tokens ni extracts reales.

---

## Video (Loom u otro)

- [ ] **90–120 s** por proyecto: problema → pantalla → frase de cierre (“implementaciones similares para tu negocio”).
- [ ] Audio claro; si hay datos sensibles, usar **demo con datos ficticios**.

---

## Freelance (Colombia / LATAM)

- [ ] Perfil en **Workana** / **Fiverr** / **Freelancer** con mismas palabras clave: automatización, Google Sheets, Telegram, integraciones, PYME.
- [ ] Primer servicio: **diagnóstico barato** para obtener primera reseña y testimonio.

---

## Opcional

- [ ] **Notion público** o **Carrd**: una URL con lista de proyectos + email/WhatsApp negocio.
- [ ] Dominio propio solo cuando ya tengas oferta clara.

---

## Qué evitar al inicio

- Discursos genéricos (“experto en IA”) sin captura ni caso de uso.
- Mezclar en el mismo párrafo **empleo corporativo** y **freelance** sin separar mensajes (adapta según audiencia).
