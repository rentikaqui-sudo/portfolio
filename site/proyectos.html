Proyecto 01

Project 01

Mi Asistente Financiero

Personal Finance Assistant

Gemini · Google Sheets · Telegram · Node.js · Railway

En curso In progress

Problema

Problem

Registrar gastos y créditos a mano desde correos bancarios consume tiempo y pierde el detalle entre flujo de caja real y deuda de tarjeta. Los datos críticos quedan en el inbox, no en un sistema.

Manually logging expenses from bank emails is slow and blurs real cash flow vs. credit-card debt. Critical data stays in the inbox, not in a system.

Solución diseñada

Designed solution

Pipeline que lee correos automáticamente, clasifica cada transacción con IA (Gemini) en pestañas dedicadas: transacciones, transferencias, inversiones. Cuando la confianza del modelo es baja, envía un mensaje a Telegram para confirmación humana antes de guardar. Reportes recurrentes corren en la nube (Railway).

A pipeline reads emails automatically, classifies each transaction with AI (Gemini) into dedicated tabs: transactions, transfers, investments. When model confidence is low, it sends a Telegram message for human confirmation before saving. Recurring reports run in the cloud (Railway).

Resultado

Result

Cero entrada manual de gastos. Separación limpia de flujo de caja vs. deuda. Revisión humana donde el dato es delicado — no deja que la IA decida sola sobre registros fiscales.

Zero manual expense entry. Clean separation of cash flow vs. debt. Human review where data is sensitive — AI doesn't decide alone on fiscal records.

Proyecto 02

Project 02

Selvato Dashboard

Shopify · Next.js · Tailwind · Recharts · MockAdapter

En curso In progress

Qué es

What it is

Panel ejecutivo para una marca colombiana de apparel en Shopify. Concentra KPIs de negocio en un solo lugar: inicio con métricas clave, ventas filtrables, inventario editable (demo), CRM, comportamiento web (GA4), publicidad Meta, chat asistente, calendario y alertas de stock.

Executive dashboard for a Colombian apparel brand on Shopify. Consolidates business KPIs in one place: a home with key metrics, filtered sales, editable inventory (demo), CRM, web behaviour (GA4), Meta advertising, assistant chat, calendar, and stock alerts.

Arquitectura de datos

Data architecture

Patrón Adaptador: hoy corre con MockAdapter en memoria. La misma interfaz permite enchufar Shopify, Meta y GA4 sin reescribir la UI — el dato cambia de fuente, la pantalla sigue igual.

Adapter pattern: currently runs with an in-memory MockAdapter. The same interface plugs in Shopify, Meta, and GA4 without rewriting the UI — the data source changes, the screen stays the same.

Proyecto 03 — Piloto

Project 03 — Pilot

QPC — Club de Pádel

Telegram · Python · Google Sheets · AI Agent

Bot que registra ventas y reparte la cuenta entre jugadores con confirmación explícita antes de persistir cualquier dato. Respaldo contable en Google Sheets.

Bot that logs sales and splits bills across players with explicit confirmation before persisting any data. Operational accounting backed by Google Sheets.

Arquitectura: capa de agente IA para lenguaje natural + herramientas deterministas (precios fijos, reglas de cancha) para que el agente no improvise en datos críticos.

Architecture: AI agent layer for natural language + deterministic tools (fixed pricing, court rules) so the agent doesn't improvise on critical data.
